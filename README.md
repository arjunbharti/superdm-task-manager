This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app). <br/>
Component library used: [ShadCN](https://ui.shadcn.com/) <br/>
TailwindCSS for styling

## Project Setup

First, install the dependencies:
```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Features:

### 🎯 Task Management
- View tasks organized by status (Open, In Progress, Closed)
- Real-time task status updates with automatic tab transitions
- Rich task details including priority, labels, assignees, and due dates
- Detailed task view with comment history

### ⌨️ Keyboard-First Navigation
- Arrow keys (↑/↓) to navigate through tasks
- Enter to open task details
- Number keys (1/2/3) for quick status changes
- Left/Right arrows to navigate between tasks in detail view
- Tab navigation for all interactive elements

### 🔍 Advanced Filtering & Sorting
- Real-time search across task names, labels, and assignees
- Sort by multiple fields (Priority, Created At, Due Date)
- Persistent sorting preferences
- Clear sorting option

### 🔒 Data Persistence
- Local storage for tasks and preferences
- Persistent search queries
- Saved tab selection
- Maintained sort configurations
